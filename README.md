# T21 · APK oficiales

Descarga e instala la versión oficial de T21 para Android 8.0 o posterior:

**[Descargar T21.apk](https://github.com/Estuar05/T21-releases/releases/latest/download/T21.apk)**

[Versiones y novedades](https://github.com/Estuar05/T21-releases/releases)

T21 gestiona clientes, servicios, citas, recordatorios y respaldos de un salón de belleza. La agenda se almacena en el teléfono, sin registro.

La aplicación consulta este repositorio y descarga las nuevas versiones automáticamente. Android solicita confirmar la instalación. Las actualizaciones oficiales conservan los datos. Puedes buscar o instalar una actualización desde Ajustes → Actualizaciones.

Si tienes una APK de prueba firmada con otra clave, exporta primero tu respaldo en T21. Android no permite reemplazar una firma distinta: desinstala la versión de prueba, instala la oficial y restaura el respaldo. Las actualizaciones oficiales siguientes ya no necesitan desinstalar.

El código fuente se mantiene en un repositorio privado. Este repositorio contiene únicamente la distribución y su publicador. Los APK y el manifiesto se publican juntos en GitHub Releases; el manifiesto incluye versión, tamaño y SHA-256. La aplicación comprueba también el paquete y la firma antes de ofrecer la instalación.
